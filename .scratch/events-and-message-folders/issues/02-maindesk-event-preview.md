# 02: Maindesk-Ereignisvorschau auf STU-Niveau bringen

**What to build:** Spielende sehen auf dem Maindesk eine klare Vorschau der zehn neuesten globalen Ereignisse mit vollständigem Datum und Uhrzeit, Orts-/Layerhinweis, verständlichem Leerzustand und einem Link zur vollständigen Ereignishistory.

**Blocked by:** 01: Globale Ereignis-API absichern und durchsuchbar machen.

**Status:** resolved

- [ ] Der Maindesk zeigt höchstens zehn aktuelle globale Ereignisse aus derselben Ereignisquelle wie die spätere History.
- [ ] Jeder Eintrag zeigt vollständiges lokalisiertes Datum und Uhrzeit sowie einen Orts-/Layerhinweis, sofern vorhanden.
- [ ] Ohne Ereignisse erscheint ein eindeutiger Leerzustand.
- [ ] Ein sichtbarer Link führt zur globalen Ereignishistory.
- [ ] Integrationstests prüfen Anzahl, Zeitdarstellung, Leerzustand und History-Navigation.
