# Faction modifiers

Status as of 2026-10-27. The persisted faction modifiers are currently seeded and returned by the faction module, but no gameplay module reads them yet.

| Modifier | Effective today | Reader |
|---|---|---|
| `hullMultiplier` | No | None outside the faction module |
| `shieldMultiplier` | No | None outside the faction module |
| `cargoMultiplier` | No | None outside the faction module |
| `researchMultiplier` | No | None outside the faction module |
| `colonyGrowthMultiplier` | No | None outside the faction module |
| `tradeModifier` | No | None outside the faction module |

The implementation and product decision for making these values effective belongs to STU parity issue `tmw-FA1b`.
